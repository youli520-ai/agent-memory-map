# 基准方法论：0/20 → 20/20

## 题目设计原则
- 模糊问法（模拟用户回忆口吻），刻意避免与语料字面量重合——测换说法/缩写/跨句指代；
- ground truth 事先用会话库标题核实；
- 判定：召回引擎前 k 结果命中 ground truth 所在会话（父子会话同根算命中）。

## 迭代实录

| 引擎 | 命中 | 关键变量 |
|------|------|----------|
| FTS 关键词（多词 AND） | 0/20 | 任一词无字面量命中即全灭；≤2 字词在 trigram 索引中恒盲 |
| 语义 dense（摘要级语料） | 8/20 | 语料=标题+首问+末答；主题在会话中部时漏 |
| 语义 dense（消息级语料，仅用户消息） | 8/20 | 中段主题变好、纯摘要题变差——命中集换了但总分没涨 |
| + BM25 词法 RRF（单面词法） | 8/20 | 融合零增益：词法侧被短消息噪声拖垮 |
| 双面语料 dense（+助手长消息） | 10/20 | 专名多在助手侧——「只嵌用户消息」是语料面盲区 |
| 双面词法 + 双面 dense RRF | 11/20 | 单通道断崖信号被融合平均淹没（词法第一名沉到 rank 20+） |
| **+ 父子同根计分** | **15/20 (k=3) / 17/20 (k=5)** | 会话拆父子链导致 strict 计分系统性低估——同一会话命中常报在父/子另一端 |
| **+ 别名机制 + 通道强提名保位** | **20/20 (k=3=k=5)** | 别名修跨词表 miss；强提名修「词法第一名被融合淹没」 |

## 四条可复用教训

1. **语料面先于融合面**：融合没增益时先查语料构成（谁的消息被索引），别调融合权重；
2. **计分口径是隐藏变量**：多层级会话存储（父子链/线程/树）必须做同根归并，否则严格计分系统性低估召回；
3. **单通道强信号不该被融合淹没**：RRF 对「一路断崖领先、另一路排名靠后」的会话不公平——通道强提名保位（每通道第一名保送）是对症解；
4. **别名是关键词盲区的正规军**：语义模型解决大部分换说法，残余跨词表 miss（自动标题 vs 用户口吻）用显式别名表补，两者互补而非互斥。

## 已知边界
- 语义模型对「跨词表改写」（如自动标题是产品代号、用户说的是功能描述）区分不动——别名表是补丁；
- ground truth 会随时间衰减：事实被更晚的会话更新后，旧会话作为标准答案会误判——复测前先核 ground truth 权威性。
